# Turnify - PP2

- Mantener React + TypeScript y la API Express + Prisma/PostgreSQL actuales.
- Backend: rutas, controladores, schemas y servicios separados por módulo.
- Autorizar en el servidor y filtrar siempre por el usuario de la sesión.
- No aceptar un ID de usuario desde un filtro para decidir de quién son los datos.
- No publicar secretos ni usar datos personales reales en seeds o pruebas.
- Listados principales paginados en el servidor, con orden estable y filtros validados.
- Mantener las estadísticas independientes de la página que se está mostrando.
- Antes de entregar: compilar ambos proyectos, ejecutar pruebas unitarias y probar
  la API contra una base aislada. Informar las comprobaciones pendientes.
- No reescribir el historial de Git ni atribuir aportes ajenos a otro integrante.
- Cambios de alcance, integraciones y publicación se coordinan con el equipo.
